# tinta. — submarca de negra.

## Vínculo con negra.

**negra.** es la oveja que no sigue el rebaño: software a medida para que la operación se vea y se ejecute (hoy: hoteles rurales en Mallorca).

**tinta.** es la misma tesis aplicada a **procesos productivos**:

| | negra. | tinta. |
|---|---|---|
| Arena | Hospitality / hotel | Industria ligera · bodega · planta |
| Promesa | El hotel en el móvil | La operación escrita · bots que ejecutan |
| Enemigo | WhatsApp + Excel + SES/ecotasa | Planillas + mails + “así lo hacemos siempre” |
| Entrega | App/ops a medida | Software + ingeniería de procesos + bots |
| Señal | Oveja negra | Oveja con casco / robot de proceso |

**Regla de marca:** negra. = casa madre. tinta. = vertical de **desarrollo de software, automatización e ingeniería de procesos** (bots de tareas). Misma voz, mismo rigor, otro campo.

**Por qué “tinta.”**  
1. **Vino:** en Mendoza, la tinta (Malbec y blends) es el producto.  
2. **Proceso:** la tinta es lo que deja rastro — el bot escribe, el sistema registra, la operación no se pierde.  
3. **Familia:** misma tipografía condensada, mismo punto final; acento pasa de naranja hotel a **malbec**.

Lockup comercial: `tinta.` · una marca de `negra.`

## Beachhead

Bodegas medianas y boutique de Mendoza (Luján, Maipú, Valle de Uco, East Mendoza) con enoturismo o exportación, 10–200 empleados, dueño presente o gerente de operaciones + enólogo.
